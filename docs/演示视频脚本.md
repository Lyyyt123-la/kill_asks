# 问数 AskData · 演示视频脚本（6 分 15 秒 · C 方案：录屏 + 字幕 + AI 配音）

> 用法：先按《录制操作卡》完成录屏（建议 1920×1080、浏览器 110%），把录屏导入剪映 → 粘贴字幕文件 `docs/演示视频字幕.srt` → 用「文本朗读/AI 配音」一键生成旁白 → 按本脚本时间轴对齐画面。
> 字幕与旁白文字完全一致；配音语速建议 1.0x，段落之间留 0.3–0.5 秒停顿。

---

## 一、基本信息

| 项目 | 内容 |
|---|---|
| 作品名称 | 问数 AskData — 基于自然语言交互的数据分析平台 |
| 时长 | 6:15（素材不足可拉长到 7:30，不要超过 8 分钟） |
| 形式 | 纯录屏 + 字幕 + AI 配音（可选真人出镜片头 5 秒） |
| 分辨率 | 1920×1080，浏览器缩放 110%，隐藏书签栏 |
| 录制工具 | OBS Studio / QQ 录屏 / Windows 自带录屏均可 |
| 配音 | 剪映「文本朗读」或任意 AI 配音（推荐青年男声/女声，语速 1.0） |

## 二、录制前准备（10 分钟）

1. 运行 `scripts/reset_demo.ps1`（清空历史数据并载入双11示例数据）；
2. 确认 `http://127.0.0.1:8000` 可以打开，右上角显示模型为 `qwen-plus`；
3. 准备好素材文件：`demo_data/documents/2025年Q3经营情况报告.pdf`、`各渠道退款率截图.png`；
4. 浏览器缩放 110%，按 F11 全屏，关闭通知；
5. 先完整走 1 遍流程（不录），确认每个问题都能在 15 秒内出结果；
6. 兜底：若模型超时，重试一次；仍失败则切到 `MOCK_MODE=on` 录制演示模式（回答里会显示“演示模式”标记，视频中避开该段即可）。

## 六、备选旁白（如果时间不够，用这一版 4 分钟）

业务查数要等两天、不会 SQL、数据还散落在 PDF 和截图里——这是三道门槛。问数 AskData 用一句中文提问，直接给出 SQL、图表和结论。上传双11数据，问各区域销售额对比，几秒出结果；继续追问最低的三个品类，它记得上下文；展开 SQL 可以核对，右侧检查器能看结果表和字段。更关键的是，它能把 PDF 财报里的表格直接变成数据集，并回答带引用的文档问题；连截图里的表格也能识别。技术上，我们做了 Schema 注入、SQL 只读校验、失败自动重试和模型评测，最终选择 qwen-plus，单问 8–12 秒。问数 AskData，让数据回答。广东科贸职业学院，指导老师林龙键，团队成员罗勇添、辛嘉炜、林俊宁。
