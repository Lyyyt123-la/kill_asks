# 部署指南

## 一、本地演示（最快）

```powershell
pwsh -ExecutionPolicy Bypass -File scripts\setup.ps1    # 首次：装依赖 + 生成演示数据
pwsh -ExecutionPolicy Bypass -File scripts\dev.ps1      # 启动前后端
```

- 开发模式：<http://127.0.0.1:5173>
- 生产单端口：先 `pwsh -ExecutionPolicy Bypass -File scripts\build.ps1`，再启动后端，访问 <http://127.0.0.1:8000>

## 二、Docker（云服务器推荐）

```bash
git clone https://github.com/Lyyyt123-la/kill_asks.git
cd kill_asks
cp backend/.env.example backend/.env
# 编辑 backend/.env，填入 LLM_API_KEY（百炼 Key）
docker compose up -d --build
```

访问 `http://服务器IP:8000`。`backend/data` 已挂载到宿主机 `./data`，容器重启不丢数据。

### 公网安全建议

在 `backend/.env` 中增加：

```ini
APP_ACCESS_CODE=你的访问口令
RATE_LIMIT_PER_MIN=20
```

设置后，访问地址需要带口令：

```
http://服务器IP:8000/?code=你的访问口令
```

前端会自动读取 URL 中的 `code` 并保存，后续 API 请求自动携带口令。
同时配置了每分钟限流，防止模型额度被刷。

## 三、Render 免费部署（保底方案）

1. 用 GitHub 账号登录 <https://render.com>；
2. New → Blueprint → 选择 `Lyyyt123-la/kill_asks` 仓库；
3. Render 会读取 `render.yaml`，在环境变量中填入：
   - `LLM_API_KEY`：百炼 API Key
   - `APP_ACCESS_CODE`：访问口令（建议设置）
4. 部署完成后访问 `https://<服务名>.onrender.com/?code=<口令>`。

注意：Render 免费实例会休眠，首次访问可能等待 30–60 秒；且免费实例不带持久磁盘，上传的数据在重启后会丢失（示例数据可一键重新载入）。

## 四、临时公网演示（录视频/临时展示）

```powershell
# 需要 Node.js；在本机后端运行时执行
npx --yes localtunnel --port 8000
```

命令会输出类似 `https://xxx.loca.lt` 的地址；兼容机开机期间可访问。首次访问若出现 Tunnel Password 提示，密码为 <https://loca.lt/mytunnelpassword> 页面上显示的值（当前网络公网 IP）。

> 该方式仅适合临时演示，正式提交建议使用云服务器 + Docker，地址长期有效。
